# Project auto-resume and Vietnamese routing — 2026-09-07

## Change scope

The owner asked the system to carry out continuation without handing the next step back to them. The existing reviewed private bridge gains an explicit `auto_resume` opt-in, supplied only from server-side memory. On initial authenticated page restoration, the client reads owned project metadata and, when opted in, resumes the linked thread once per handoff version and account/browser. Afterward a user's manual thread selection is respected. Other accounts without opt-in retain ordinary history restoration. All restore calls are metadata/history operations; they never call an AI model or consume question quota.

The same canonical lexical ticker recognizer is embedded into research parsing, authenticated chat and browser entry points. It preserves Unicode/accent boundaries, masks lookup phrases, URLs and email addresses, and disambiguates ordinary three-letter words. Explicit message tickers supersede stale client selections. Discussing a sector for one named ticker does not imply scanning the whole market. Pocket Pivot follow-ups retain the current ticker, methodology explanations remain knowledge questions, and explicit investment horizons are inferred server-side.

The recognizer identifies mentions; it is not a market listing authority. The existing HOSE, fresh-data, licensed-data and action gates remain responsible for whether analysis/action is allowed. A token with an explicit stock cue can still be ambiguous; no claim of perfect natural-language interpretation is made.

## Privacy and operating boundary

Private handoff text stays in the existing owner/thread-scoped memory table. No private portfolio, addresses, chat transcripts, account identifiers or credentials are included here. Opt-in metadata is not an authorization claim. An available bridge still requires server-side ownership checks. The feature does not expose history to Guests, change entitlements, approve payments, send mail, rotate keys or purchase API credit.

This is reviewed context transfer and on-request reading of owned website history, not native automatic synchronization of every ChatGPT Project message. The provider-credit problem is independent; auto-restoring context does not prove successful live model generation.
